# Your Level Up — Gym Website

A clean, bold website for **Your Level Up**, an independent gym.

## Files

- `index.html` — Main website page
- `style.css` — All styles

## Customise Before Going Live

- [ ] Replace placeholder phone number (`01606 000 000`) with real number

- [ ] Update opening hours if different
- [ ] Update pricing if different
- [ ] Replace testimonials with real member reviews
- [ ] Add your gym's address to the footer
- [ ] Update social media links (Instagram, Facebook)
- [ ] Add real photos (replace the YLU placeholder block in the About section)

## Hosting via GitHub Pages

Once uploaded to GitHub, you can host this for free using GitHub Pages:

1. Go to your repository on GitHub
2. Click **Settings** → **Pages**
3. Under *Source*, select **Deploy from a branch**
4. Choose **main** branch and **/ (root)** folder
5. Click **Save** — your site will be live at `https://yourusername.github.io/your-level-up`
